# Reimagined helmets

Built-in ImageGen generated these new paintings from the outline-only PNG references and the painted weapon style reference. The SVG interior planes and shading were deliberately discarded. V1 files are exploratory studies, not active assets.

The preparation script removes the white background and assigns steel, lining, and brass material masks. Black mask pixels preserve the ivory horns; layer exports include those pixels with the shell. Helmet affixes are not yet authored.

### closed V2
Use case stylized-concept. Design a NEW helmet using image 1 ONLY as a loose outer silhouette guide; freely reinterpret proportions for believable wearable construction. Image 2 is paint/material style reference only. A believable closed medieval greathelm: gently domed riveted crown, continuous steel faceplate, one narrow horizontal eye slit split by a subtle nasal reinforcement, neat breathing perforations, restrained aged brass lower rim, dark leather lining only visible along underside. Broad clean structural planes, no decorative sharp plates over the cheeks. Hand-painted dark fantasy game inventory art, rich dimensional forged materials, worn edge highlights, restrained visible broad brushwork, coherent soft upper-left light with gentle fill so BOTH sides remain readable. NO enormous black shadow planes, no hard vertical half-face darkness, no arbitrary graphic ridges, no copying weapon shapes, no vector look or glossy 3D. Neutral slate steel, dark brown leather, warm aged brass fittings. Mostly front view with slight perspective. Single EMPTY helmet centered, full object with 70px clear margin, portrait 1024x1536, pure white flat background without shadow, no labels, no emblems.
